# Escape Pod — committed schemas

The JSON Schemas (Draft 2020-12) of Escape Pod's data interfaces, as listed in the manual's
`Interfaces` chapter (Standard §23.2). Tests validate the program's output against these files,
so a change here is an interface change and needs a version bump in the ICD.
